# NETFULL 3.0 — Go-Live Checklist

Este checklist se firma contra el SHA final que aparece en Pass A, Pass B, CI y los manifests. Los controles no se marcan de forma anticipada dentro del source para evitar afirmar resultados antes de ejecutar el commit final.

- [ ] Revisión visual externa aprobada
- [ ] QA Pass A aprobado
- [ ] QA Pass B aprobado
- [ ] GitHub CI aprobado
- [ ] SEO aprobado
- [ ] Seguridad aprobada
- [ ] Accesibilidad aprobada
- [ ] Funnel aprobado
- [ ] Backup/recovery entendido
- [ ] Merge autorizado
- [ ] Deploy autorizado

`Merge autorizado` y `Deploy autorizado` deben permanecer sin marcar hasta una instrucción expresa del owner.
